\chapter{Introduction}

\section{Background}
In the modern dining experience, selecting a meal is often time-consuming and frustrating. Customers rely on scattered online reviews and social media discussions, which makes it difficult to identify the best dishes. The lack of a centralized and structured system for aggregating and analyzing this information leads to inefficiencies and uncertainty when choosing what to order. Users must manually sift through multiple sources to determine popular menu items, creating information overload and suboptimal choices. Restaurants and food enthusiasts therefore lack a streamlined solution that compiles feedback into meaningful insights.

\section{Objectives}
This project aims to develop DishDive, an AI-powered system that analyzes online customer feedback to recommend top-rated dishes in Bangkok. It will extract and process social media comments, perform sentiment analysis, and summarize insights. The system provides a searchable restaurant database, an interactive summary map, and personalized recommendations based on user preferences. A mobile application (iOS/Android) serves as the primary user-friendly interface, ensuring a seamless experience.

\section{Scope}
	extbf{Functions and Features:}
\begin{itemize}
	\item Analyze social media comments and reviews to surface dish-level insights.
	\item Provide a restaurant database with search, filtering, and personalization.
	\item Deliver recommendations based on user preferences and blacklists.
	\item Offer mobile access (iOS/Android) as the primary interaction channel.
\end{itemize}

	extbf{Users:}
\begin{itemize}
	\item Diners seeking the best dishes in Bangkok.
	\item Restaurants interested in structured feedback to improve menus.
\end{itemize}

	extbf{Supported Platforms:}
\begin{itemize}
	\item Mobile application (iOS/Android) as primary; backend services and database as supporting components.
\end{itemize}

\section{Expected Benefits}
DishDive is expected to reduce the time users spend manually searching for reviews by transforming unstructured, scattered opinions into summarized, data-driven insights. Users gain confident, informed dining decisions; restaurants gain actionable feedback to refine their offerings. Personalized and up-to-date recommendations improve user satisfaction, while structured analytics help restaurants optimize menus.
